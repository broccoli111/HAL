# HAL Book III - Engineering Standards

## Authority

Book III is subordinate to Book I (the Constitution) and Book II (the Architecture Specification). It defines the mandatory common engineering practices used to implement and maintain the approved architecture. It is not a component-specification book; detailed subsystem requirements belong in Book IV.

## Source gate

Place the final source documents in `source/` with these exact names before drafting begins:

- `BOOK_I_CONSTITUTION.pdf`
- `BOOK_II_ARCHITECTURE_SPECIFICATION.pdf`

The project is intentionally at the source-assessment stage because those documents were absent when initialized. See `reviews/SOURCE_DOCUMENT_ASSESSMENT.md`.
