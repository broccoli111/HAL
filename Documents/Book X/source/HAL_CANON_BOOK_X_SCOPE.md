# Canon Scope Record - Book X

## Canonical title

Book X - Canonical Terminology and Information Model

## Question answered

What does every HAL term mean?

## Mandate

Book X is the semantic foundation shared by architecture, software, governance, interfaces, and operations. It contains the canonical glossary, concept hierarchy, entity definitions, relationships, information model, ownership and authority semantics, lifecycle and state terminology, trust/security/verification/operational terminology, deprecated terms, forbidden ambiguous terms, acronym registry, naming conventions, and cross-book term index.

## Initial core entities

Owner; HAL; Identity; Presence; Intent; Authority; Delegation; Capability; Action; Transaction; Decision Object; Attention Object; Outcome Object; Knowledge; Experience; Pattern; Wisdom; Trust Domain; Treaty; Constitutional Firewall; Reality Boundary; Evidence; Verification; Certification; Constitutional invariant.

## Production dependency

Book X follows Book III and precedes detailed Book IV component specifications and Book IX interface contracts. Book X terms constrain later wording but remain subordinate to the normative meaning established by Books I-III.
