# HAL Canon Completion Program

This directory contains the integration controls used to complete Books V, VI, VII, VIII, and IX without modifying finalized Books I, II, III, IV, or X.

The primary agent is the Canon Integrator. Book workstreams may draft independently only within their assigned book directories. A book is not final until it passes its dependency gate and the Canon Integrator's constitutional, architecture, semantic, cross-book, and publication audits.

## Authority

1. Book I - Constitution
2. Book II - Architecture Specification
3. Book III - Engineering Standards
4. Book IV - Component Specifications
5. Book IX - Interface and Protocol Reference
6. Book V - Operations Manual
7. Book VI - Security, Privacy, and Trust Manual
8. Book VII - Governance and Stewardship Manual
9. Book VIII - Verification and Certification Manual
10. Book X - Canonical Terminology and Information Model

The numeric order is not the authority order for every subject. Book X governs shared meaning; Book IX governs machine-facing contracts; Books V-VIII govern their assigned procedural domains. None may alter a higher-order source.
